# OKOA Donation Platform

A donation management platform for OKOA, a charitable organization similar to Goodwill. The platform allows users to track donations made via M-Pesa and provides WhatsApp integration for communication.

## Features

- 💰 **M-Pesa Integration**: Displays the M-Pesa number (+254713370833) for donations
- 📊 **Pie Chart Analytics**: Visualizes donation distribution across categories
- 📱 **WhatsApp Integration**: Direct chat link to +254713370833
- 📋 **Donation History**: Tracks all donations with timestamps
- 📈 **Real-time Stats**: Shows total raised, donation count, and average donation

## Categories

- General Fund
- Education
- Healthcare
- Food & Nutrition
- Shelter
